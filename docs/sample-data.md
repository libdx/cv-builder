# Fictional sample data

Joe Doe is a fictional senior software engineer. Every employer, employment
date, education entry, career statement, evidence note, and practice example
was supplied as demonstration content. The avatar is a generic geometric
silhouette, not a photograph. Contact URLs and email use `example.com`; the
phone uses a fictional 555 number. No example is intended as a real person's CV.

Broadly reusable technical skills demonstrate backend, frontend, data, cloud,
delivery, and agent-assisted engineering workflows. Similar skills do not imply
that the fictional work history describes the original developer.

The sample marks selected statements `verified` only to demonstrate the model's
rendering gates. Provenance explicitly says `fictional_sample`. Candidate and
rejected examples demonstrate exclusion rules. One fictional private practice
tests disclosure validation; it contains no confidential information.

When building a real CV, replace the sample and obtain real confirmation for
each claim. Never convert fictional evidence into real-user evidence merely by
changing the name or provenance label.
